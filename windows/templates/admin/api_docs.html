REST API reference for programmatic access to this news portal.

Authentication

Every API endpoint (except GET /api/version and GET /api/search) requires authentication. Two methods are accepted:

  • Session cookie — automatically used when you are logged in to the admin panel.
  • API key header — send {{if .APIKey}}X-API-Key: {{.APIKey}}{{else}}X-API-Key: <your-key>{{end}} in the request. The key is set via the API_KEY environment variable.
{{if eq .APIKey ""}}
Az API_KEY környezeti változó ezen az oldalon nincs beállítva. Az API-t kulcsos hitelesítéssel nem lehet használni.
{{end}}

Unauthenticated requests receive:

HTTP/1.1 401 Unauthorized
Content-Type: application/json

{"error":"Hitelesítés szükséges"}

curl example (API key):

curl -H "X-API-Key: {{if .APIKey}}{{.APIKey}}{{else}}YOUR_KEY{{end}}" {{if .SiteURL}}{{.SiteURL}}{{else}}https://example.com{{end}}/api/articles

Analytics

The complete data set behind the Analytics dashboard — cookie-free, first-party traffic measurement stored in your own database. All endpoints are GET, require authentication and return JSON.

MethodURLDescription
GET/api/analyticsFull report (every section at once)
GET/api/analytics/summaryHeadline KPIs
GET/api/analytics/timeseriesViews / visitors / sessions over time
GET/api/analytics/breakdownsEvery dimension table
GET/api/analytics/breakdowns/{dimension}A single dimension table
GET/api/analytics/heatmapWeekday × hour matrix
GET/api/analytics/realtimeTraffic in the last N minutes
If the built-in analytics is switched off (ANALYTICS_ENABLED=false) or the database is unavailable, every endpoint answers 503.
Query parameters

The period and filters are interpreted identically by every endpoint.

ParameterTypeDefaultDescription
rangestring7dtoday, yesterday, 24h, 7d, 28d, 30d, 90d, mtd, ytd, 12mo, custom
fromdate—YYYY-MM-DD, with range=custom
todate—YYYY-MM-DD, inclusive
granularitystringautohour, day or month — overrides the bucket size
comparebooleantruefalse skips the previous-period aggregations
limitinteger15Rows per breakdown table, max 500
minutesinteger30Realtime endpoint only, max 180

Filters — any combination, all exact matches:

ParameterValues
page_typehome, article, category, author, tag, search, page, forum, marketplace, webshop, other
pathExact URL path, e.g. /article/rtx-5090-teszt
channeldirect, organic, social, referral, campaign, internal, ai
devicedesktop, mobile, tablet
countryISO 3166-1 alpha-2 code, e.g. HU
ref_hostReferrer host, e.g. google.hu
categoryCategory name
authorAuthor name

A filter applies to every section of the response: summary, time series, breakdowns and heatmap. An unknown range silently falls back to 7d.

Full report

Everything in one request: summary, previous period, time series, all breakdowns and the heatmap. This is the most expensive endpoint — use the section endpoints when you need only one part. 

GET /api/analytics?range=28d&channel=organic&limit=20

Response (abridged):

{
  "range": {
    "key":           "28d",
    "from":          "2026-06-29T00:00:00+02:00",
    "to":            "2026-07-27T00:00:00+02:00",
    "previous_from": "2026-06-01T00:00:00+02:00",
    "previous_to":   "2026-06-29T00:00:00+02:00",
    "granularity":   "day",
    "timezone":      "Europe/Budapest"
  },
  "filter":  { "channel": "organic" },
  "summary": { <summary object> },
  "previous":{ <summary object> },
  "series":         [ { "bucket": "2026-06-29", "views": 2612, "visitors": 1620, "sessions": 1854 } ],
  "previous_series":[ { "bucket": "2026-06-01", "views": 2280, "visitors": 1410, "sessions": 1602 } ],
  "breakdowns":     { "pages": [...], "channels": [...], "referrers": [...], ... },
  "heatmap":        [ { "weekday": 2, "hour": 9, "views": 187 } ]
}
Sections that were not requested are absent from the JSON rather than empty. range and filter are always present. With compare=false the previous, previous_series, range.previous_from and range.previous_to fields are omitted.

curl:

curl -H "X-API-Key: {{if .APIKey}}{{.APIKey}}{{else}}YOUR_KEY{{end}}" "{{if .SiteURL}}{{.SiteURL}}{{else}}https://example.com{{end}}/api/analytics?range=28d"
Summary

The headline KPIs plus the same numbers for the previous period. Fastest endpoint.

GET /api/analytics/summary?range=today&compare=false
{
  "range":   { "key": "today", "granularity": "hour", "timezone": "Europe/Budapest", ... },
  "filter":  {},
  "summary": {
    "views":             1204,
    "visitors":          812,
    "sessions":          903,
    "views_per_session": 1.3333,
    "avg_engagement_ms": 88000,
    "bounce_rate":       44.2,
    "engagement_rate":   55.8,
    "outbound":          31
  }
}
FieldTypeMeaning
viewsintegerPage views
visitorsintegerUnique visitors (see the note below)
sessionsintegerVisits; 30 minutes of inactivity starts a new one
views_per_sessionfloatviews / sessions
avg_engagement_msintegerAverage time actually spent on the page, in milliseconds
bounce_ratefloatPercentage of single-page sessions without engagement
engagement_ratefloatPercentage of sessions longer than 10s or scrolled past 50%
outboundintegerOutbound link clicks and downloads
Reading visitors: the visitor identifier is a hash salted with a key that is regenerated every day, so the same person receives a new identifier each day. Over a multi-day range visitors is therefore the sum of daily uniques, not the true unique count for the period. This is the price of consent-free, cookie-less measurement; sessions and views are exact.
Time series

Bucket size is chosen automatically (hour up to 48 hours, day up to 120 days, month above that) and can be overridden with granularity.

GranularityBucket formatExample
hourYYYY-MM-DDTHH2026-07-27T14
dayYYYY-MM-DD2026-07-27
monthYYYY-MM2026-07
 
GET /api/analytics/timeseries?range=90d&granularity=month&compare=false
{
  "range":  { "key": "90d", "granularity": "month", "timezone": "Europe/Budapest", ... },
  "filter": {},
  "series": [
    { "bucket": "2026-05", "views": 41200, "visitors": 25600, "sessions": 29100 },
    { "bucket": "2026-06", "views": 44870, "visitors": 27340, "sessions": 31020 }
  ]
}

Buckets are in the ANALYTICS_TIMEZONE local time, and only buckets with traffic are returned — fill the gaps with zeroes client-side if you draw a continuous chart.

Breakdowns

Without a dimension every table is returned at once; with one, only that table.

DimensionContents
pagesMost viewed pages (key = path, label = page title)
entry_pagesLanding pages — first page of each session
exit_pagesExit pages — last page of each session
channelsGA4-style default channel grouping
referrersReferrer hosts (label = recognised brand name)
utm_sources, utm_mediums, utm_campaignsCampaign parameters
devices, browsers, osTechnology
countries, languagesGeography (country needs a CDN country header)
page_types, categories, authorsEditorial performance
outboundOutbound links and downloads (key = target URL)

Row object:

FieldTypeMeaning
keystringRaw dimension value — pass it back as a filter
labelstringDisplay name when one exists, otherwise empty
viewsintegerPage views
visitorsintegerUnique visitors — session count for entry/exit pages
avg_engagement_msintegerAverage time on page in milliseconds
bounce_ratefloatPercentage; only meaningful for entry_pages and exit_pages, 0 elsewhere

{

How did people find one specific article?

curl -H "X-API-Key: {{if .APIKey}}{{.APIKey}}{{else}}YOUR_KEY{{end}}" \
  "{{if .SiteURL}}{{.SiteURL}}{{else}}https://example.com{{end}}/api/analytics/breakdowns/channels?range=7d&path=/article/rtx-5090-teszt"

An unknown dimension name returns 404 listing the valid names.

Heatmap

Traffic by weekday and hour. Only non-zero cells are returned.

GET /api/analytics/heatmap?range=90d
{
  "range":   { "key": "90d", "timezone": "Europe/Budapest", ... },
  "filter":  {},
  "heatmap": [
    { "weekday": 2, "hour": 9,  "views": 187 },
    { "weekday": 2, "hour": 10, "views": 204 }
  ]
}
FieldMeaning
weekday1 = Sunday … 7 = Saturday (MongoDB $dayOfWeek convention)
hour0–23 in the ANALYTICS_TIMEZONE local time
viewsPage views in that weekday + hour cell
Realtime

Traffic over the last minutes minutes (default 30, max 180). Period and filter parameters do not apply to this endpoint. 

GET /api/analytics/realtime?minutes=5
{
  "minutes":         30,
  "active_visitors": 47,
  "views":           312,
  "per_minute":    [ { "bucket": "2026-07-27T18:41", "views": 9, "visitors": 7, "sessions": 0 } ],
  "top_pages":     [ { "key": "/article/rtx-5090-teszt", "label": "RTX 5090 teszt", "views": 18, "visitors": 12, ... } ],
  "top_channels":  [ { "key": "organic", "label": "organic", "views": 22, "visitors": 15, ... } ],
  "top_countries": [ { "key": "HU", "label": "HU", "views": 41, "visitors": 28, ... } ],
  "devices":       [ { "key": "mobile", "label": "mobile", "views": 28, "visitors": 19, ... } ]
}

per_minute[].bucket is a UTC timestamp in YYYY-MM-DDTHH:MM form, unlike the other endpoints which bucket in local time.

Create article
MethodURLAuth
POST /api/articles Required

Request body (JSON):

FieldTypeRequiredNotes
titlestringYesArticle title. Slug is auto-generated.
summarystringShort excerpt shown in listings.
contentstringMarkdown body.
authorstringDisplay name (used when author_id is absent).
author_idstringObjectID of an existing author.
categorystringDisplay name.
category_idstringObjectID of an existing category.
tagsstring[]Tag list.
image_urlstringFeatured image URL. If S3 is configured, external URLs are auto-imported to the media library.
ai_content_disclosurestringYesAI declaration for the article content: none, assisted, or generated. For backward compatibility only, omitted values are stored as none.
ai_image_disclosurestringYes, if image_url is setAI declaration for the featured image: unmodified, modified, or generated. For backward compatibility only, an omitted value is stored as unmodified when image_url is set.
publishedboolPublish immediately (default: false).
publish_atstring (RFC3339)Scheduled publish time. Null or omit to use the current time when published=true.

curl:

curl -X POST -H "X-API-Key: {{if .APIKey}}{{.APIKey}}{{else}}YOUR_KEY{{end}}" -H "Content-Type: application/json" \
  -d '{
    "title":      "My New Article",
    "summary":    "A short summary.",
    "content":    "## Introduction\n\nHello world.",
    "category":   "Technology",
    "category_id":"664a000000000000000000bb",
    "tags":       ["go", "tutorial"],
    "ai_content_disclosure": "none",
    "published":  true
  }' \
  {{if .SiteURL}}{{.SiteURL}}{{else}}https://example.com{{end}}/api/articles

Response 201: the created article object.
Response 400: {"error":"A cím megadása kötelező"}

Same body fields as Create article, plus:

FieldTypeNotes

    "published": true
  }' \
